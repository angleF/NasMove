# NasMove

## 项目目标

提供面向 NAS 的可靠文件传输应用。

## 非目标

当前阶段不提供已实现功能之外的使用说明。

## 当前开发状态

核心传输与恢复模块已经建立，Windows 离线 UI 和功能接线已完成。真实 Synology 故障注入、生产 SMB 会话接线与 macOS 发布验证暂缓，续作边界和恢复命令已归档。
