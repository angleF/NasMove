# NasMove 每 NAS 配置的文件并发设计

## 目标

为每个 NAS 连接配置增加“并发文件数”设置。该设置控制同一个迁移任务内可同时执行的文件数，默认值为 `2`，允许范围为 `1`～`4`。

该设置不改变队列的单任务执行模型：同一时刻仍只启动一个迁移任务。它也不把一个文件拆成多个并发分片；单个文件继续使用既有断点续传、完整回读校验和原子提交协议。

## 已确认的产品语义

| 项目 | 决定 |
| --- | --- |
| 配置归属 | NAS 连接配置 |
| 生效范围 | 一个任务内的多个文件 |
| 默认值 | `2` |
| 可选范围 | `1`～`4` |
| 多任务并行 | 不支持；队列保持串行 |
| 单文件分片并行 | 不支持；继续使用已有断点续传协议 |

选择较低上限是为了限制 SMB 会话、NAS 磁盘随机 I/O 与本地哈希负载，且使暂停、取消和恢复的边界保持可推导。

## 数据与兼容性

`ConnectionConfig` 新增不可空字段 `max_parallel_items: int = 2`，并在领域对象构造时校验取值为 `1`～`4`。

数据库从 schema 5 升级到 schema 6：

1. `connection_profiles` 新增 `max_parallel_items INTEGER NOT NULL DEFAULT 2 CHECK (max_parallel_items BETWEEN 1 AND 4)`。
2. `tasks` 新增 `connection_max_parallel_items INTEGER NOT NULL DEFAULT 2 CHECK (connection_max_parallel_items BETWEEN 1 AND 4)`。
3. 现有连接配置和未完成任务均以 `2` 回填；任务读取时必须使用任务快照，后续修改连接配置不能改变已入队任务的并发度。
4. 更新 schema 指纹、版本识别、崩溃恢复测试和 repository 的读写映射。

密码不进入新增字段、任务快照或日志，仍只存在 macOS Keychain。

## 界面与交互

连接配置页新增“传输性能”区块，使用整数选择控件展示“并发文件数”，并显示说明“同一迁移任务内同时处理的文件数；任务队列仍顺序执行”。

控件默认显示 `2`，范围限制在 `1`～`4`。加载、编辑、清空配置及连接测试成功后的持久化必须保留该值。工作台侧栏仅展示当前配置摘要，不重复提供会产生歧义的运行时覆盖项。

## 执行模型

队列协调器继续一次只调度一个任务。`TransferEngine` 在任务进入 `RUNNING` 后，根据任务连接快照创建最多 `max_parallel_items` 个项目工作槽：

1. 每个槽一次只处理一个 `TransferItemRecord` 的完整生命周期：恢复、复制、完整校验、提交，再按移动语义将源文件移入废纸篓。
2. 每个槽使用独立 SMB 会话和独立 SQLite 线程连接。不得跨线程共享现有 SMB session、文件句柄或 SQLite connection。
3. 文件级事件继续带 `task_id` 与 `item_id`；聚合进度在 UI 主线程汇总。任务只在所有项目结束后才转换为最终 `VERIFYING`、`COMMITTING` 和终态。
4. 当并发数为 `1` 时，执行顺序与当前串行实现一致。
5. 一个项目出现不可恢复失败时，不再取新的项目；已启动项目收到共享取消请求，并在检查点边界退出。所有活动项目安全结束、各自状态持久化后，任务才进入失败或等待网络状态。
6. 暂停与用户取消遵循相同的共享令牌与检查点边界。退出后可由现有恢复逻辑按每个项目的独立检查点继续。

空目录项目仍按原来的计划顺序处理，防止与其子文件的创建、提交或清理产生竞态。

## 错误处理与恢复

并发槽的异常不得被吞掉。每个失败项目保留其独立错误分类、重试次数、检查点与最终状态；任务结果汇总失败、警告和完成数量。连接中断时，所有槽先安全落盘并释放各自会话，再由既有重试和恢复流程决定是否继续。

应用关闭仍先请求队列在安全边界停止，随后等待并发项目工作槽释放 SQLite 线程连接与 SMB 会话，最后关闭 repository。

## 验收与测试

1. 领域测试：默认值、边界 `1`／`4`、非法值拒绝。
2. 配置 UI 测试：新建、编辑、载入与清空配置均正确显示并发文件数。
3. 持久化测试：schema 5 升级、默认回填、配置 round-trip、任务快照不可被后续配置编辑改写。
4. 执行测试：并发 `1` 保持串行；并发 `2` 和 `4` 从不超过上限；每个活动项目使用独立会话和 repository 线程连接。
5. 可靠性测试：多个项目并发时暂停、取消、网络失败、单项目校验失败、强制退出与恢复均不会删除未验证源文件。
6. UI 回归：三种主题以及 `1100×760`、`1600×1000` 下的连接配置与工作台截图可读。

## 非目标

本次不实现多个迁移任务同时运行、不实现单个文件多分片上传、不自动根据 CPU 或带宽动态调节并发数，也不改变现有 NAS 账号、Keychain 与冲突策略语义。
