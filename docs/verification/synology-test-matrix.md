# Synology 故障验证矩阵

## 安全门禁

- 必须设置 `NASMOVE_TEST_SYNOLOGY=1` 与 `NASMOVE_TEST_SYNOLOGY_READY=1`。
- `NASMOVE_SYNOLOGY_TEST_ROOT` 必须位于 `NasMoveTest/<run-id>` 下。
- TCP 故障代理只能监听本机回环地址。
- DSM 管理命令仅作用于唯一测试子目录；临时账号在用例结束后删除。
- 密码、认证报文和可从公网访问的地址不写入本报告。
